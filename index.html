6 · Open points

To confirm before the dashboard logic is built

1
TG Usage option 3 score

The scoring table gives “self-made lesson plan / method” 5 points, but the footnote says 7. This page uses the table (5). Confirm which is final.

2
Workbook availability (Q52) scale

The table scores 0–40% / 40–70% / 70–100% as 0 / 3 / 5 (out of 5). A footnote says 0 / 5 / 10 and has a typo (“70–110%”). This page uses the table, since Q52 + Q53 must add to 10.

3
Old question numbers in footnotes

Footnotes refer to Q18, Q21, Q40 and Q41. In the 21 Sept checklist these are Q45, Q48, Q52 and Q53. The column header also cites the 31 Aug checklist.

4
Which framework applies

The workbook does not say what triggers Class 1–5 vs 6–8. This page assumes Q6 (class observed): Class 1–5 → primary framework, Class 6–8 → upper primary framework. A Composite school can therefore be scored on either, visit by visit.

5
Q45 for upper primary

Q45 (teaching method) is still asked when Class 6–8 is observed, but is not scored there. Confirm that is intended.

6
U5 / U6 are school-level

STEM kit and project-based learning are school-wide questions in Section 9, not classroom observations. In a Composite school they are asked even when a Class 1–5 lesson is observed; they only count when the observed class is 6–8.

7
Missing answers at school level

NA handling is defined only for block level (NA removed from the denominator). Confirm whether a school composite is re-weighted across the themes that have data, or shown as incomplete.

8
Repeat visits in a month

Not specified whether the dashboard uses the latest visit per school or averages all visits in the period.

1 · Data model

From one visit to two dashboards

1Mentor visitFills the Balvatika SSD checklist for one school.
2ValidateUDISE match, branching, present ≤ enrolled.
3Latest visitOne record per school per month.
4FiltersDistrict, block, area, period, ECCE personnel.
5Score K1–K10Option map → Yes / No per running centre.
6FFB verdictAll 10 KPIs Yes = Fully Functional.
7Roll upBlock, district, state: count ÷ count.
Fully Functional Balvatika = K1 ∧ K2 ∧ … ∧ K10 (all Yes in the same visit)  ·  % FFB = FFB centres ÷ centres running at visit
Operational dashboard = visit counts and timings over every visit · all other KPIs over each school’s latest visit

Each KPI is Yes or No for a running centre. There are no scores or weights. For multi-select questions, one ✓ option is enough. 1.11 (other classes the Educator teaches) and 4.6 (3 hours of play) are not part of FFB.

Timestamps needed from the app

Avg time per visit needs the form start time and submit time on every record. Avg time per assessment needs start and end times for Section 3 (SPOT). Neither is in the current export.

i
ECCE Personnel filter (1.5)

Combined (default): all schools. Educator only: running centres with 1.5 = Educator. Others only: running with any other role. Non-running centres appear only under Combined, because 1.5 is asked only when the centre is running.

7 · Counting rules

Rules that apply to both dashboards

RuleDefinition
Unit of analysisOne record per school per month: its latest visit (by visit date, then submission time). “All months” = latest visit in the year.
Order of filtersDistrict / block / area type → year and month → latest visit per school → ECCE personnel.
Running centresSchools whose latest visit has 1.3 = Yes. Base for every FFB KPI and most operational KPIs.
Educator-run centresRunning centres with 1.5 = Educator. Base for 1.11.
Learning space field1.12 (Educator-run) and 1.13 (others) combined into one field for K1.
Roll-upBlock, district and state values are computed from school records directly: count ÷ count, Σ ÷ Σ. Never average lower-level percentages.
Schools not visitedExcluded from every % except coverage.
8 · Open points

To confirm before the build

1
K1: co-located Anganwadi

The FFBV column passes “In the co-located Anganwadi” and “In the verandah”. An earlier CSF rule failed the co-located Anganwadi. 1.13 has no FFBV rule; the 1.12 rule is applied.

2
K3: learning corners

FFBV column is blank. This page counts only “All four corners” as Yes.

3
K10: WASH

FFBV column is blank. Handwash unit or toilet counts as Yes.

4
1.9 wording

1.9 asks for enrolled “and present” 5-6 children, and 1.10 asks for present again. Reword 1.9 to enrolment only so K9 and attendance are reliable.

5
Branching after 1.3 = No

The checklist note to close the form sits on 1.5’s row. This page assumes the form closes right after 1.4.

6
Section 3 (SPOT)

No questions yet, so no KPI uses it. Add start and end timestamps when it is built.

7
Enrolment vs observed centre

1.7–1.10 cover all Anganwadis in the school, while observation questions cover the one Balvatika named in 1.6. In schools with more than one centre, K9 and the other KPIs describe different units.

8
Blank answers

Proposed: a blank answer for a running centre makes the KPI No and is flagged for data quality.
